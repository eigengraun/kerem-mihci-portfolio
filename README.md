# Kerem Mıhçı Portfolio OS

An interactive, desktop-inspired personal portfolio operating system showcasing Graphic Design, Brand Identity, Web Design & Development, and Motion + AI Production.

## Development

Install dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Production Build & Validation

Validate TypeScript and compile the production build:
```bash
npm run build
```

Run linter:
```bash
npm run lint
```

Start the production server:
```bash
npm run start
```

## Environment Variables

Configure `.env` or set environment variables in your hosting environment (Hostinger):

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

Refer to `.env.example` for reference.

## Deployment Architecture

- **Repository**: GitHub
- **Hosting**: Hostinger (Node.js runtime / Next.js)
- **Domain**: Custom Domain with SSL/HTTPS
